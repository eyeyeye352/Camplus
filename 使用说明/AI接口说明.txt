================================================================================
                        Camplus AI向量服务接口说明
================================================================================

一、功能概述
--------------------------------------------------------------------------------
本模块提供三个核心AI功能：
1. 文本向量化 - 将文本转换为向量表示（支持稠密向量+稀疏向量）
2. 向量检索 - 在指定数据库表中检索相似内容
3. 答案生成 - 根据问题和上下文生成回答（RAG问答）

二、环境要求
--------------------------------------------------------------------------------
1. BGE-M3 ONNX模型文件
   - 路径配置：application.properties 中的 bge-m3.model-path
   - 默认路径：D:/models/bge-m3-onnx/

2. Ollama大语言模型（用于答案生成）
   - 地址：http://localhost:11434
   - 模型名：qwen2.5:7b

三、服务类调用方式
--------------------------------------------------------------------------------
【注入服务类】

@Autowired
private VectorService vectorService;

@Autowired
private AnswerGenerationService answerGenerationService;

@Autowired
private BgeM3OnnxService bgeM3OnnxService;

--------------------------------------------------------------------------------
【功能1：文本向量化】

// 单文本向量化
VectorEmbeddingResponse response = vectorService.embedText("如何选课？");

// 返回结果包含：
// - denseVector: 稠密向量（float[]）
// - sparseVector: 稀疏向量（Map<Integer, Float>）
// - text: 原始输入文本
// - success: 是否成功

--------------------------------------------------------------------------------
【功能2：向量检索】

// 在FAQ向量表中检索
List<VectorSearchResult> results = vectorService.search(
    "faq_vector_store",    // 表名：faq_vector_store 或 knowledge_vector_store
    "如何选课？"            // 查询文本
);

// 返回结果包含：
// - recordId: 记录ID
// - content: 匹配的文本内容
// - similarityScore: 相似度分数
// - tableName: 来源表名
// 注：固定返回1条最相似结果，相似度阈值固定为0.6

--------------------------------------------------------------------------------
【功能3：答案生成】

// 方式A：直接生成（需提供上下文）
AnswerGenerationResponse answer = answerGenerationService.generateAnswer(
    "选课流程是什么？",     // 用户问题
    contextList            // 上下文文本列表
);

// 方式B：完整RAG流程（自动检索+生成）
AnswerGenerationResponse answer = answerGenerationService.ragAnswer("选课流程是什么？");

// 返回结果包含：
// - answer: 生成的答案
// - contextsUsed: 使用的上下文
// - confidence: 置信度（0-1）
// - success: 是否成功

四、REST API调用方式
--------------------------------------------------------------------------------
【功能1：文本向量化】
POST /api/vector/embed
请求体：{"text": "如何选课？"}
响应：
{
    "success": true,
    "denseVector": [0.123, -0.456, ...],
    "sparseVector": {"1234": 0.5, "5678": 0.3},
    "text": "如何选课？"
}

--------------------------------------------------------------------------------
【功能2：向量检索】
POST /api/vector/search
请求体：
{
    "tableName": "faq_vector_store",
    "queryText": "如何选课？"
}
响应：
{
    "success": true,
    "results": [
        {
            "recordId": 1,
            "content": "选课流程说明...",
            "similarityScore": 0.85,
            "tableName": "faq_vector_store"
        }
    ],
    "totalCount": 1
}
注：返回条数和相似度阈值不可配置，固定为1条、阈值0.6

--------------------------------------------------------------------------------
【功能3：答案生成】
POST /api/vector/generate
请求体：
{
    "question": "选课流程是什么？",
    "contexts": ["上下文1", "上下文2"]
}
响应：
{
    "success": true,
    "answer": "选课流程如下...",
    "contextsUsed": ["上下文1", "上下文2"],
    "confidence": 0.85
}

--------------------------------------------------------------------------------
【功能4：完整RAG问答】
POST /api/vector/rag
请求体：{"question": "选课流程是什么？"}
响应：
{
    "success": true,
    "answer": "根据知识库信息，选课流程如下...",
    "contextsUsed": ["检索到的上下文"],
    "confidence": 0.85
}

--------------------------------------------------------------------------------
【健康检查】
GET /api/vector/health
响应：
{
    "modelInitialized": true
}

五、支持的数据库表
--------------------------------------------------------------------------------
1. faq_vector_store - FAQ问答向量表
   字段：id, faq_id, question, answer, question_embedding,
         answer_embedding, combined_embedding

2. knowledge_vector_store - 知识库文档向量表
   字段：id, doc_id, chunk_index, chunk_content, chunk_embedding,
         chunk_metadata

六、注意事项
--------------------------------------------------------------------------------
1. 模型未初始化时，向量化功能会返回失败，但不影响应用启动
2. 向量检索返回条数固定为1条，相似度阈值固定为0.6（系统内置，不可配置）
3. 答案生成依赖Ollama服务，请确保Ollama已启动并加载了qwen2.5:7b模型
4. 稀疏向量用于关键词匹配，可提高检索精度

七、配置参数说明（application.properties）
--------------------------------------------------------------------------------
bge-m3.model-path=D:/models/bge-m3-onnx/    # ONNX模型路径
bge-m3.dense-weight=0.6                      # 稠密向量权重
bge-m3.sparse-weight=0.4                     # 稀疏向量权重

ollama.base-url=http://localhost:11434       # Ollama服务地址
ollama.chat-model-name=qwen2.5:7b            # 大语言模型名称
ollama.temperature=0.7                       # 生成温度
