# userInfo 模块代码说明

## 概览

userInfo 模块负责用户信息展示与个人资料修改，前端位于 `src/main/webapp/userInfo/`，后端位于 `src/main/java/com/camplus/login/`（与登录注册共用 login 模块）。

---

## 前端（userInfo 模块）

### 文件结构

| 文件 | 作用 |
|---|---|
| `userInfo.html` | 页面结构：侧边菜单 + 主内容区（信息展示 + 四个修改表单） |
| `userInfo.css` | 样式：青蓝色主题，侧边菜单左侧渐变透明，按钮图标+文字 |
| `userInfo.js` | 逻辑：菜单控制、音乐控制、登录态UI、四个表单提交 |

### 页面布局

- **右上角按钮**：音乐控制（right: 100px）、菜单按钮（right: 20px, z-index: 100001）
- **侧边菜单**：占据右半屏（width: 50%），左侧 25% 区域渐变透明，菜单内容在实色区
- **主内容区**：垂直滚动，显示用户信息卡片和四个编辑表单卡片

### 侧边菜单结构

```
.side-menu（右侧弹出，opacity 控制显隐，visibility 控制可点击）
├── .menu-header（头像 + 账号名，margin-left: 25%）

├── .menu-content（3列网格，正方形按钮，图标在上文字在下）
```

### 登录态 UI（纯 CSS 类控制）

| 元素 | 未登录 | 已登录 |
|---|---|---|
| `.avatar-circle` | 显示用户默认头像图标 | 显示笑脸图标（CSS 切换） |
| `#accountName` | "游客" | 用户名 |
| `#menuLoginBtn` | "登入/注册" | 隐藏（`display: none`） |
| `#avatarCircle` | 无 `.logged-in` 类 | 有 `.logged-in` 类 |

### sessionStorage 字段

| key | 说明 |
|---|---|
| `userId` | 用户ID |
| `username` | 用户名 |
| `email` | 邮箱（可为空字符串） |
| `phone` | 手机号（可为空字符串） |
| `nickname` | 昵称 |
| `avatarUrl` | 头像URL |
| `role` | 角色：0=普通用户，1=管理员 |
| `status` | 账号状态：0=禁用，1=正常 |

### 表单提交（axios + URLSearchParams）

所有修改接口均为 `POST`，通过 `axios.post(url, params, { withCredentials: true })` 发送。

**后端返回结构**：`Result<T>` — `{ success: boolean, msg: string, data: T }`

前端用 `const { data: result } = await axios.post(...)` 接收，`result.data` 即后端 `Result.data`。

**修改成功后**：`updateUserInfo(user)` 更新 sessionStorage 所有字段 + 页面显示 + 菜单账号名。

## 后端（login 模块 — 用户相关接口）

### 文件结构

| 层次 | 文件 |
|---|---|
| Controller | `controller/UserController.java` |
| Service 接口 | `service/UserService.java` |
| Service 实现 | `service/impl/UserServiceImpl.java` |
| Mapper 接口 | `mappers/UserMapper.java` |
| Mapper XML | `resources/mybatis/mappers/UserMapper.xml` |
| 实体类 | `entity/User.java` |

### 接口列表

| 接口 | 方法 | 参数 | 返回 | 说明 |
|---|---|---|---|---|
| `/login` | POST | `loginAccount`, `password`, `rememberMe` | `Result<User>` | 通用登录（用户名/邮箱/手机号） |
| `/register` | POST | `username`, `email`, `phone`, `password` | `Result<User>` | 注册 |
| `/user/updateUsername` | POST | `userId`, `newUsername` | `Result<User>` | 修改用户名 |
| `/user/updateEmail` | POST | `userId`, `newEmail` | `Result<User>` | 修改邮箱 |
| `/user/updatePhone` | POST | `userId`, `newPhone` | `Result<User>` | 修改手机号 |
| `/user/updatePassword` | POST | `userId`, `oldPassword`, `newPassword` | `Result<String>` | 修改密码 |

### 业务逻辑

**用户名/邮箱/手机号修改（updateUsername / updateEmail / updatePhone）**：
1. 校验新值是否已被他人占用（排除自己）
2. 执行 UPDATE，更新 `update_time = NOW()`
3. 返回更新后的完整 User 对象

**密码修改（updatePassword）**：
1. 根据 `userId` 查询当前用户
2. 将旧密码明文 MD5 加密后与数据库 `password_hash` 比对
3. 不一致返回失败
4. 一致则将新密码 MD5 加密后更新

### User 实体类字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `userId` | Long | 主键 |
| `username` | String | 用户名（唯一） |
| `passwordHash` | String | MD5 加密密码 |
| `nickname` | String | 昵称 |
| `email` | String | 邮箱（唯一） |
| `phone` | String | 手机号（唯一） |
| `avatarUrl` | String | 头像URL |
| `role` | Integer | 0=普通用户，1=管理员 |
| `status` | Integer | 0=禁用，1=正常 |
| `lastLoginTime` | LocalDateTime | 最后登录时间 |
| `loginErrorCount` | Integer | 登录错误次数（达5次锁定30分钟） |
| `lockTime` | LocalDateTime | 锁定时间 |
| `createTime` | LocalDateTime | 创建时间 |
| `updateTime` | LocalDateTime | 更新时间 |

### 数据库 users 表字段映射

MyBatis `UserResultMap` 驼峰映射：
- `user_id` → `userId`
- `password_hash` → `passwordHash`
- `nickname` → `nickname`
- `avatar_url` → `avatarUrl`
- `last_login_time` → `lastLoginTime`
- `login_error_count` → `loginErrorCount`
- `lock_time` → `lockTime`
- `create_time` → `createTime`
- `update_time` → `updateTime`

### 登录锁定机制

- 密码错误累计 5 次后自动锁定账户 30 分钟
- 锁定期间 `lockTime` 不为空，`login()` 检查是否在解锁时间内
- 超过 30 分钟自动解锁，清除 `lockTime` 和 `loginErrorCount`
