# 前端 home 模块 代码说明

本模块负责 Camplus 系统的**首页**：页面标题、右上角的音乐/菜单按钮、侧边菜单；根据登录态呈现不同 UI。

---

## 1. 文件结构

| 文件 | 作用 |
|---|---|
| `index.html` | 页面结构：固定标题、音乐按钮、菜单按钮、背景音乐、侧边菜单、主内容区 |
| `index.css` | 样式：深色背景、青蓝色系、侧边菜单左侧渐变透明、正方形图标按钮 |
| `index.js` | 逻辑：菜单开关、音乐控制、登录态 UI、admin 按钮权限校验 |

---

## 2. index.html 页面元素

| 元素 | 说明 |
|---|---|
| `.fixed-title` | 左下角固定标题 `<h1>Camplus</h1>`，鼠标进入左下角 200×200 区域时淡入升起。 |
| `.music-button` `#musicButton` | 右上角音乐开关（right: 100px），SVG 图标，点击切换播放/暂停。 |
| `.menu-button` `#menuButton` | 右上角菜单按钮（right: 20px, z-index: 100001），点击打开侧边菜单。 |
| `#bgMusic` | 背景音乐播放器，`src="../assets/musics/webbgm.mp3"`。 |
| `.side-menu` `#sideMenu` | 右侧弹出菜单（width: 50%），`opacity` 控制显隐。内部结构：`.menu-header`（头像+账号名）、`.menu-content`（3列网格按钮）、`.menu-footer`（底部登出）。 |

**侧边菜单结构**：
```
.side-menu
├── .menu-header（margin-left: 25%，落在实色区）
│   └── .account-area: .avatar-circle + #accountName
├── .menu-content（margin-left: 25%，3列正方形网格）
│   ├── 问答平台（menu-item--bright）
│   ├── 首页
│   ├── 用户
│   ├── 管理者（#adminMenuItem）
│   ├── 帮助
│   └── 用户贡献
└── .menu-footer（margin-left: 25%，底部居中）
    └── #menuLoginBtn "登入/注册"
```

## 4. index.js 核心逻辑

### 初始化

获取 DOM 引用：`.fixedTitle`, `.menuButton`, `.sideMenu`, `.musicButton`, `.bgMusic`, `.avatarCircle`, `.accountName`, `.menuLoginBtn`, `.adminMenuItem`。

### 登录态 UI（纯 CSS 类）

```javascript
function updateLoginUI() {
    const username = sessionStorage.getItem('username');
    if (username) {
        accountName.textContent = username;
        avatarCircle.classList.add('logged-in');     // 头像变笑脸
        menuLoginBtn.textContent = '登出';
        menuLoginBtn.classList.add('logged-in');     // 隐藏"登入/注册"按钮
    } else {
        accountName.textContent = '游客';
        avatarCircle.classList.remove('logged-in');
        menuLoginBtn.textContent = '登入/注册';
        menuLoginBtn.classList.remove('logged-in');
    }
}
```

| 元素 | 未登录 | 已登录 |
|---|---|---|
| `.avatar-circle` | 用户默认头像图标 | 笑脸图标（CSS 切换 `.logged-in`） |
| `#accountName` | "游客" | 用户名 |
| `#menuLoginBtn` | "登入/注册" | "登出"（`display: none`） |

### 音乐控制

- `isMusicPlaying` 状态变量，初始 `true`。
- `toggleMusic()`：切换播放/暂停 + `.music-slash` 斜杠显隐。
- 首屏自动播放尝试 `bgMusic.play().catch(...)`，失败时 `isMusicPlaying = false`。
- 首次 body 点击时若未播放则自动启动（绕过自动播放限制）。
- `musicButton` 点击 `e.stopPropagation()` 避免触发 body 点击。

### 菜单控制

- `menuButton` 点击 → `sideMenu.classList.toggle('active')`。

### 登出逻辑

```javascript
menuLoginBtn.addEventListener('click', () => {
    if (sessionStorage.getItem('username')) {
        sessionStorage.clear();
        location.reload();
    } else {
        goToLogin();
    }
});
```

### admin 按钮权限校验

点击"管理者"时，先调用后端查询角色，只有 `role === 1`（管理员）才跳转：

```javascript
adminMenuItem.addEventListener('click', async (e) => {
    if (!sessionStorage.getItem('username')) {
        e.preventDefault();
        goToLogin();
        return;
    }
    e.preventDefault();
    const userId = sessionStorage.getItem('userId');
    const { data: result } = await axios.post('/user/getRole',
        new URLSearchParams({ userId }),
        { withCredentials: true });
    if (result.success && (result.data === 1 || result.data === '1')) {
        window.location.href = '../admin/admin.html';
    } else {
        alert('您不是管理员！');
    }
});
```

## 5. sessionStorage 字段（共 8 个）

| key | 说明 |
|---|---|
| `userId` | 用户ID |
| `username` | 用户名 |
| `email` | 邮箱 |
| `phone` | 手机号 |
| `nickname` | 昵称 |
| `avatarUrl` | 头像URL |
| `role` | 0=普通用户，1=管理员 |
| `status` | 0=禁用，1=正常 |

首页**只读取不写入**，写入操作在 login.js 登录/注册成功回调中完成。
