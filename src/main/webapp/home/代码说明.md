# 前端 home 模块 代码说明

本模块负责 Camplus 系统的**首页**：页面标题、右上角的音乐/用户/菜单按钮、侧边菜单；以及根据"是否登录"呈现不同状态。

---

## 目录结构

```
src/main/webapp/home/
├── index.html       # 首页 HTML
├── index.css        # 首页样式（含动态标题、菜单、按钮等）
└── index.js         # 首页交互：登录态判定、音乐、菜单、跳转
```

---

## 1. index.html

### 页面元素一览

| 元素 | 说明 |
|------|------|
| `.fixed-title` | 左下角固定标题 `<h1>Camplus</h1>`，鼠标进入左下角 200×200 区域时淡入升起。 |
| `.music-button #musicButton` | 右上角音乐开关，SVG 图标，点击切换播放/暂停，音乐暂停时显示斜线 `.music-slash`（`display: none` ↔ `""`）。 |
| `.user-button #userButton` | 右上角用户图标（位于 music-button 和 menu-button 之间），**点击始终跳转登录页**（与菜单底部的 menuLoginBtn 功能类似，但位置更醒目）。 |
| `.menu-button #menuButton` | 右上角菜单按钮，点击切换侧边栏。 |
| `#bgMusic audio` | 背景音乐播放器，`src="../assets/musics/webbgm.mp3"`。 |
| `.menu-overlay #menuOverlay` | 侧边栏遮罩层，点击可关闭菜单。 |
| `.side-menu #sideMenu` | 右侧抽屉式菜单（内部结构：`.border-container` → `.border-gradient` 彩色渐变边框 + `.border-inner` 黑色背景 + `.menu-content` 两列链接 + `.menu-footer` 底部按钮）。 |
| `.menu-item` 菜单链接 | `问答平台 / 首页 / 用户 / 管理者入口 / 帮助 / 用户贡献` 共六项；其中"管理者入口"由 `adminMenuItem` JS 变量判断登录态。 |
| `.menu-footer > .menu-login-btn #menuLoginBtn` | **核心登录态切换元素**：<br>- 未登录：`<span>` 显示"登入/注册"，可点击跳转登录页。<br>- 已登录：显示用户名，且设置 `pointer-events: none` 不可点击。 |

### HTML 与 login.html 的差异

1. **没有登录弹窗**（首页本身不需要输入账号密码）。
2. **多了 `.fixed-title` 固定标题**（login 页面有动态圆点背景，没有首页标题）。
3. **`.menu-login-btn` 是 `<span>` 而非 `<button>`**——因为登录后要承载"显示用户名"这一文本功能，使用 span 更合适且无需去除 button 自带样式。
4. **`.user-button` 存在于首页**——右上角用户图标，未登录时跳转登录页。

## 2. index.css

### 布局与样式要点

| 样式类 | 说明 |
|--------|------|
| `.fixed-title` | 左下角 `position: fixed; left:30px; bottom:30px`，初始`translateY(20px)` 下沉半透明；`.active` 时升至正常位置、完全不透明。 |
| `.menu-button`（right:20px） `.user-button`（right:100px） `.music-button`（right:180px） | 右上角三个圆形 40×40 图标，从右到左依次：**菜单 → 用户 → 音乐**。`opacity: 0.5` 默认半透明，hover 变亮，active 缩小到 0.95。 |
| `.menu-overlay` | 全屏半透明遮罩，`.active` 时显示。 |
| `.side-menu` | 280px 宽的右侧抽屉，`.active` 时 opacity 1 显示；内含彩色渐变边框 + 黑色内边（3px）形成"霓虹"效果。 |
| `.menu-content` | CSS Grid 两列布局，`padding: 20px`，gap 12px。 |
| `.menu-item` | 每项为圆角卡片，`background-color: rgba(255,255,255,0.08)`，hover 变为粉色 `rgba(255,0,128,0.2)` 并整体上移。 |
| `.menu-footer > .menu-login-btn` | 菜单底部的"登入/注册"或用户名显示：<br>`max-width:140px + text-overflow:ellipsis + white-space:nowrap` 防止长用户名溢出；<br>默认 `cursor: pointer; opacity: 0.8`，登录态时 JS 会设置 `cursor: default; pointer-events: none; opacity: 1`。 |
| `@keyframes gradientRotate` | 45° 方向上 `#ff0080 → #ff8c00 → #40e0d0 → #8a2be2 → #ff0080` 的颜色渐变循环动画，4 秒一次。 |
| `@font-face { Camplus_title }` | 自定义标题字体，`../assets/fonts/Camplus标题字体.ttf`。 |
| `body` | `width:100vw; height:100vh; overflow:hidden; background-color:#2a2a2a`。 |

### 与 login.css 的差异

- login.css 有 12 个浮动圆点 `.dot1 ~ .dot12`，首页没有——首页背景色固定 `#2a2a2a`。
- login.css 中 `.music-button` 的 `right` 也是 100px（与 user-button 重叠），但 login.html 没有 user-button 元素，所以视觉上没问题。
- 首页 `.menu-login-btn` 多了 `max-width`、`text-overflow: ellipsis` 和 `display:block; text-align:center`，以便显示用户名时不溢出。

## 3. index.js ⭐ 核心逻辑

### 初始化

| 步骤 | 代码 |
|------|------|
| DOM 引用 | `fixedTitle`, `menuButton`, `sideMenu`, `menuOverlay`, `musicButton`, `bgMusic`, `userButton`, `menuLoginBtn`, `adminMenuItem`, `activationZone = 200` |
| 登录态 UI 初始化 | 页面加载完成后立即调用 `updateLoginUI()`（详见下文）。 |

### 登录态判定函数（核心）

```javascript
function updateLoginUI() {
    const username = sessionStorage.getItem('username');
    if (username) {
        // 已登录
        menuLoginBtn.textContent = username;      // 显示用户名，替代"登入/注册"
        menuLoginBtn.style.pointerEvents = 'none'; // 禁止点击（防止反复点）
        menuLoginBtn.style.opacity = '1';
        menuLoginBtn.style.cursor = 'default';
    } else {
        // 未登录
        menuLoginBtn.textContent = '登入/注册';
        menuLoginBtn.style.pointerEvents = 'auto';
        menuLoginBtn.style.opacity = '0.8';
        menuLoginBtn.style.cursor = 'pointer';
    }
}
```

### 三个点击事件与跳转规则

| 元素 | 点击行为 | 逻辑 |
|------|---------|------|
| `menuLoginBtn`（菜单底部按钮） | 未登录 → 跳 `../login/login.html`<br>已登录 → 不做任何事（`pointer-events: none` 已阻止） | `if (!sessionStorage.getItem('username')) goToLogin()` |
| `userButton`（右上角用户图标） | 始终跳登录页 | `goToLogin()` |
| `adminMenuItem`（菜单中的"管理者入口"链接） | 未登录 → `e.preventDefault()` 阻止跳转并转登录页<br>已登录 → 正常跳转到 `../admin/admin.html` | `if (!username) { e.preventDefault(); goToLogin(); }` |

### 标题触发区域

`activationZone = 200`：当鼠标同时位于左侧 200px 以内和下方 200px 以内（左下角）时，给 `.fixed-title` 添加 `active`，标题升起并完全显示。

### 音乐控制（与 login.js 一致）

- `isMusicPlaying` 状态变量。
- `toggleMusic()`：切换播放/暂停 + 显示/隐藏 `.music-slash` 斜杠。
- 首屏自动播放尝试：`bgMusic.play().catch(...)`，失败时置 `isMusicPlaying = false`。
- 首次 `document.body` 点击时若音乐未播放则自动启动，绕过浏览器的自动播放限制。
- 点击 `musicButton` 手动开关（`e.stopPropagation()` 避免冒泡触发 body 点击）。

### 菜单控制

- `menuButton` 点击 → `.side-menu` 和 `.menu-overlay` 切换 `active` class。
- `menuOverlay` 点击 → 关闭菜单。

### 与 login.js 的 sessionStorage 约定

与 login 模块**完全共用同一套 key**：`userId`、`username`、`email`、`phone`、`nickname`、`avatarUrl`、`role`、`status`。

**首页不写 sessionStorage**，只读取；写入操作**只在 login.js** 的登录/注册成功回调中发生。

## 4. 与 login 模块的数据流关系

```
┌─ login.js ───────────────────────┐     ┌─ index.js ─────────────────────────┐
│                                   │     │                                      │
│  1. 用户登录/注册成功             │     │  页面加载时：                     │
│  2. fetch('/login') 或 '/register'│     │    updateLoginUI() ← 读取 username │
│  3. 后端返回 JSON { userId, ... } │     │  显示用户名 或 "登入/注册"          │
│  4. 所有字段存入 sessionStorage   │     │  点击:                            │
│  5. alert + 跳转 /home/index.html │     │    未登录 → ../login/login.html    │
│                                   │     │    已登录 → 不跳转                 │
└───────────────────────────────────┘     └─────────────────────────────────────┘
                        ↓ 共用 sessionStorage ↓
                sessionStorage.getItem('username') 为"是否登录"判定条件
                sessionStorage.getItem('role') 可用于判断是否管理员
```

## 5. 设计要点总结

| 要点 | 说明 |
|------|------|
| 登录态判定 | `sessionStorage.getItem('username')` 是否非空 |
| 用户名显示位置 | 侧边栏菜单底部的 `.menu-login-btn`（`<span>`，非 `<button>`） |
| 未登录点击 | 菜单底部 "登入/注册"、右上角用户图标、管理员入口 → 全部跳 `../login/login.html` |
| 已登录点击 | 菜单底部用户名不可点击；用户图标仍跳登录页（预期是跳个人中心，后续可扩展）；管理员入口直接跳转（前端依赖 role 字段可进一步校验） |
| 动画 | 标题淡入升起（CSS transition）、菜单渐入、按钮 hover/active 缩放 |
| 音乐 | `bgMusic` 播放器 + 首屏点击自动启动 + 手动开关切换，与 login.js 代码结构几乎相同 |
| sessionStorage 只读不写 | 首页只读取、不修改用户信息；写入由 login/register 成功后在 login.js 中完成，避免多入口状态混乱 |
