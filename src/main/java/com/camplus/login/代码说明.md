# 后端 login 模块 代码说明

本模块负责 Camplus 系统的**用户登录、注册、个人资料修改**后端逻辑，采用 Spring Boot + MyBatis 架构。

> **更新说明**：LoginController 与 RegisterController 已合并为 `UserController`，新增 `updateUsername`、`updateEmail`、`updatePhone`、`updatePassword`、`getRole` 五个接口。

---

## 1. common.Result.java

统一响应包装类，所有 Controller 返回值均使用此类封装。

```java
Result<T> {
    boolean success;   // 请求是否成功
    String msg;        // 提示信息
    T data;           // 泛型数据体
}
```

三个静态工厂方法：
- `Result.ok(String msg, T data)` —— 成功响应，带数据
- `Result.ok(String msg)` —— 成功响应，不带数据
- `Result.fail(String msg)` —— 失败响应

| 方法 | 参数 | 返回值 | 说明 |
|---|---|---|---|

- `updateUsername/Email/Phone/Password`：均更新 `update_time = NOW()`

## 4. service.UserService.java 与 UserServiceImpl.java

### 接口方法

| 方法 | 说明 |
|---|---|
| `register(User)` | 注册，返回 boolean |
| `registerAndReturnUser(User)` | 注册并返回完整 User 对象 |
| `login(String loginAccount, String password)` | 通用登录（用户名/邮箱/手机号） |
| `updateUsername(Long, String)` | 修改用户名（唯一性校验） |
| `updateEmail(Long, String)` | 修改邮箱（唯一性校验） |
| `updatePhone(Long, String)` | 修改手机号（唯一性校验） |
| `updatePassword(Long, String, String)` | 修改密码（校验旧密码 MD5 后更新） |
| `getRole(Long)` | 查询用户角色，返回 Integer（0/1） |

### 业务实现要点

**registerAndReturnUser**：
1. 校验 username/email/phone 是否已存在
2. 初始化默认值：`role=0`, `status=1`, `loginErrorCount=0`, `lockTime=null`
3. 密码 MD5 加密后存入 `passwordHash`
4. 插入数据库，返回完整 User 对象

**login**：
1. 依次按 username → email → phone 查询
2. 锁定校验：30分钟自动解锁
3. 密码 MD5 比对，错误累加≥5次锁定账号

**updateUsername/Email/Phone**：
1. 查询新值是否被他人占用（排除自己）
2. 执行 UPDATE，返回更新后的 User 对象

**updatePassword**：
1. 旧密码 MD5 比对，不一致返回 false
2. 新密码 MD5 加密后更新

**getRole**：查询并返回用户角色，未找到返回 null

### 常量

- `MAX_ERROR_COUNT = 5`
- `LOCK_DURATION_MINUTES = 30`

## 5. controller.UserController.java

> 注：LoginController 与 RegisterController 已合并为此类。

### 接口列表

| 接口 | 方法 | 参数 | 返回 | 说明 |
|---|---|---|---|---|
| `/login` | POST | `loginAccount`, `password`, `rememberMe` | `Result<User>` | 通用登录 |
| `/register` | POST | `username`, `email`, `phone`, `password` | `Result<User>` | 注册 |
| `/user/updateUsername` | POST | `userId`, `newUsername` | `Result<User>` | 修改用户名 |
| `/user/updateEmail` | POST | `userId`, `newEmail` | `Result<User>` | 修改邮箱 |
| `/user/updatePhone` | POST | `userId`, `newPhone` | `Result<User>` | 修改手机号 |
| `/user/updatePassword` | POST | `userId`, `oldPassword`, `newPassword` | `Result<String>` | 修改密码 |
| `/user/getRole` | POST | `userId` | `Result<Integer>` | 查询用户角色 |

### getRole 接口（admin 权限校验）

```
POST /user/getRole
参数：userId  Long
返回：
    成功：{ success: true, msg: "查询成功", data: 0或1 }
    失败：{ success: false, msg: "用户不存在", data: null }
```

前端 home 模块点击"管理者"按钮时调用此接口，只有 `data === 1` 才跳转到管理员页面。

## 6. util.MD5Util.java

唯一方法：`md5Encrypt(String pwd)` → 返回 32 位十六进制 MD5 字符串。

- 用于注册时密码加密存储、登录时密码比对、修改密码时新密码加密
- 数据库存储的是 MD5 值而非明文

## 8. 前后端数据流

```
[前端 login.js]
   axios.post('/login', URLSearchParams, { withCredentials: true })
   → UserController.login()

[前端 home/index.js — admin按钮]
   axios.post('/user/getRole', URLSearchParams, { withCredentials: true })
   → UserController.getRole()
   → { success: true, data: role }
   → role === 1 ? 跳转admin页 : alert('您不是管理员！')

[前端 userInfo/userInfo.js — 修改资料]
   axios.post('/user/updateUsername', URLSearchParams, { withCredentials: true })
   → UserController.updateUsername()
   → UserService.updateUsername() → Mapper → DB
   → { success: true, data: updatedUser }
   → updateUserInfo(result.data) 更新sessionStorage和页面显示
```

## 9. 安全与限制

| 项目 | 说明 |
|---|---|
| 密码存储 | 32位 MD5 哈希值存储，明文仅传输时存在 |
| 账号锁定 | 连续5次错误锁定30分钟自动解除 |
| 唯一性校验 | username/email/phone 任一重复均拒绝注册或修改 |
| 前端 sessionStorage | 全权管理登录态，后端不维护 HttpSession |
